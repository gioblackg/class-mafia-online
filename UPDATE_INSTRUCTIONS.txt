우리 반 마피아 Online v2.4 업데이트

1. class-mafia-online-v2.4-update.zip 압축을 풉니다.
2. GitHub의 기존 class-mafia-online 저장소에서 Add file → Upload files를 누릅니다.
3. 압축을 푼 폴더 안의 파일과 public 폴더를 모두 올립니다.
4. Commit changes를 누릅니다.
5. Render가 자동 재배포되며 기존 사이트 주소는 그대로 유지됩니다.

이번 버전 핵심 변경
- 교사 화면 간소화: 학생 현황 + 현재 진행 중심
- 학생 화면 간소화: 역할(열려 있을 때) + 현재 행동만 표시
- 경찰 조사 결과를 교사 밤 결과와 지난 기록에 표시
- 테스트/기록/게임 관리는 접이식 메뉴로 정리
