우리 반 마피아 Online v2.1 업데이트 방법

1. 이 ZIP을 압축 해제합니다.
2. GitHub의 class-mafia-online 저장소를 엽니다.
3. Add file -> Upload files 를 누릅니다.
4. 압축 해제한 폴더 안의 아래 항목을 모두 끌어다 놓습니다.
   - server.js
   - package.json
   - README.md
   - public 폴더
5. 아래 Commit changes 버튼을 누릅니다.
6. Render가 GitHub 변경을 감지하여 자동 배포합니다.
7. Render 화면에서 Live가 되면 기존 주소를 그대로 사용합니다.

중요: 저장소를 새로 만들 필요가 없습니다.
