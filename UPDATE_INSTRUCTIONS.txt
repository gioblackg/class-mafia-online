우리 반 마피아 Online v2.6 업데이트

1. class-mafia-online-v2.6-update.zip 압축을 풉니다.
2. GitHub의 기존 class-mafia-online 저장소에서 Add file → Upload files를 누릅니다.
3. 압축을 푼 폴더 안의 파일과 public 폴더를 모두 올립니다.
4. Commit changes를 누릅니다.
5. Render가 자동 재배포되며 기존 사이트 주소는 그대로 유지됩니다.
