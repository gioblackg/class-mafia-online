우리 반 마피아 Online v2.3 업데이트 방법

1. GitHub의 기존 class-mafia-online 저장소를 엽니다.
2. Add file → Upload files를 누릅니다.
3. v2.3-update 압축을 푼 뒤 폴더 안의 파일과 public 폴더를 모두 끌어다 놓습니다.
4. Commit changes를 누릅니다.
5. Render가 자동으로 다시 배포할 때까지 기다립니다.
6. Render 상태가 Live가 되면 기존 주소를 그대로 사용합니다.

v2.3 주요 변경
- 경찰 조사 결과 표시 오류 수정(같은 밤에 경찰이 탈락해도 결과 확인 가능)
- 교사용 가상 학생 테스트 모드 추가
- 가상 학생 학생화면 미리보기
- 가상 학생 밤 행동/낮 투표 자동 선택
