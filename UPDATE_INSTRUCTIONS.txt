우리 반 마피아 Online v2.2 업데이트

GitHub class-mafia-online 저장소에서:
1. Add file -> Upload files
2. 이 업데이트 폴더 안의 server.js, README.md, public 폴더를 업로드
3. Commit changes
4. Render가 자동 배포될 때까지 기다림
5. 기존 onrender.com 주소 그대로 사용
