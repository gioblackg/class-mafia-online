# 우리 반 마피아 Online v2.0

교사와 학생이 같은 Wi-Fi에 연결되어 있지 않아도 사용할 수 있도록 만든 **인터넷 배포형** 버전입니다.

## 기능
- 교사: 6자리 방 생성, QR 자동 생성, 접속 학생 확인
- 마피아/경찰/의사/시민 무작위 역할 배정
- 학생: 자기 역할만 확인
- 교사: 모든 학생 역할 확인
- 마피아끼리 서로 확인 옵션
- 일차별 투표 시작/종료, 실시간 투표 완료 인원 확인
- 득표 결과, 탈락 처리, 다음 일차, 지난 투표 기록
- 3~40명, 방 생성 후 6시간 자동 만료
- 회원가입 없는 학생 입장

## 인터넷에서 쓰는 방법 (Render 기준)
이 폴더를 GitHub 저장소에 올린 뒤 Render에서 Web Service 또는 Blueprint로 배포합니다.

### 가장 간단한 순서
1. GitHub에 새 저장소를 만듭니다.
2. 이 폴더 안의 파일을 모두 저장소 최상위에 업로드합니다.
3. Render에서 새 Web Service(또는 Blueprint)를 만들고 그 GitHub 저장소를 연결합니다.
4. `render.yaml`을 사용하는 경우 설정이 자동으로 잡힙니다.
5. 배포가 끝나면 `https://...onrender.com` 형태의 주소가 생깁니다.
6. 그 주소에서 선생님이 방을 만들면 QR도 자동으로 **인터넷 주소**로 생성됩니다.

## 중요한 점
- 인터넷 배포 후에는 교사/학생이 같은 Wi-Fi일 필요가 없습니다.
- 이 버전은 수업용 단기 방에 맞춰 서버 메모리에 방 정보를 보관합니다.
- 무료 호스팅 서비스가 재시작되면 진행 중인 방이 사라질 수 있습니다. 일반적인 한 차시/수업 사용에는 적합하지만, 며칠 동안 같은 방을 유지하려면 별도 DB(Supabase 등)를 붙이는 버전이 더 적합합니다.
- 학생이 입력하는 번호/별명과 역할/투표 정보는 방이 살아 있는 동안만 사용하도록 설계되어 있습니다.

## 로컬 미리보기
Node.js 20 이상이 설치되어 있다면 `start_local_preview.bat`을 실행하면 됩니다.
이 기능은 배포 전 화면 확인용입니다. 실제로 다른 네트워크에서 접속하려면 인터넷 서버에 배포해야 합니다.
