# 우리 반 마피아 Online v2.2

교사와 학생이 서로 다른 Wi-Fi/LTE/5G에서도 사용할 수 있는 인터넷 배포형 교실 마피아 게임입니다.

## v2.2 핵심 변경 사항

- 밤 행동을 학생 태블릿에서 직접 선택하도록 변경
- 생존 학생 전원에게 **같은 밤 행동 화면** 표시
  - 마피아의 선택만 실제 처단 대상으로 반영
  - 의사의 선택만 실제 보호 대상으로 반영
  - 경찰의 선택은 개인 조사 결과로 반영
  - 시민의 선택은 결과에 영향을 주지 않는 더미 행동
- 모든 학생에게 같은 문구와 같은 형태의 후보 버튼을 표시하여 역할 노출을 줄임
- 후보 순서는 학생마다 다르게 고정되어 옆에서 손가락 위치를 봐도 선택 대상을 추측하기 어렵게 함
- 태블릿에서 후보를 약 0.8초간 **꾹 누르면 즉시 선택 완료**
- 선택 후에는 누구나 똑같은 `밤 행동 완료` 화면으로 전환
- 교사가 `밤 행동 시작`을 누르면 학생 역할 화면이 자동으로 잠김
- 교사 화면에서 전체 밤 행동 완료 인원 확인
- 교사 화면에는 시민의 더미 선택은 표시하지 않고, 실제 마피아 선택과 의사 보호만 집계해서 표시
- 경찰은 밤 종료 후 자신의 화면에서 선택한 학생이 마피아인지 개인 결과를 확인 가능
- 개인 결과는 태블릿에서 버튼을 누르고 있는 동안만 보이도록 가림
- 복수 마피아가 서로 다른 대상을 선택하면 다수 선택을 적용하고, 동률은 서버가 일정한 규칙으로 자동 결정
- 모든 생존 학생이 선택을 완료해야 `밤 결과 적용` 버튼 활성화
- 의사 보호 대상과 마피아 대상이 같으면 보호 성공, 다르면 마피아 대상 자동 탈락

## 기존 v2.1 기능 유지

- 학생 투표 선택이 자동 새로고침 때문에 풀리지 않도록 보존
- 교사 화면 역할 기본 가림 및 `역할 보기`
- 학생 역할 잠금/다시 열기
- 일차별 투표, 탈락 처리, 기록
- QR 입장 및 인터넷 접속

## GitHub / Render 업데이트 방법

현재 GitHub 저장소 `class-mafia-online`에 이 버전의 파일을 덮어 올리면 Render가 자동 배포합니다.

1. 업데이트 ZIP을 압축 해제
2. GitHub `class-mafia-online` 저장소 → `Add file` → `Upload files`
3. 압축 해제한 폴더 안의 파일/폴더를 전부 업로드
4. 같은 이름의 기존 파일을 새 파일로 덮어쓴 상태에서 `Commit changes`
5. Render 자동 배포가 끝나고 `Live`가 되면 기존 주소를 그대로 사용

기존 주소 예: `https://class-mafia-online.onrender.com`
