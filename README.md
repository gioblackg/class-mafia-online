# 우리 반 마피아 Online v2.9

이번 버전은 **기능은 그대로 유지하고 디자인만 게임풍으로 리뉴얼**한 버전입니다.

## 반영 내용
- 초록 잔디 느낌의 밝은 배경
- 둥근 메뉴형 버튼 스타일
- 교사/학생 화면을 아기자기한 게임 UI 분위기로 변경
- QR 확대 화면, 전체 역할 새창, 학생 행동 카드까지 같은 톤으로 통일
- 역할별 색상 차이는 계속 제거된 상태 유지
- 기존 기능(역할 부여, 역할 잠금, 투표, 밤 행동, 가상 학생, QR, 전체 역할 새창)은 그대로 유지
