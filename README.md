# 우리 반 마피아 Online v2.4

교실에서 태블릿으로 사용하는 인터넷 배포형 마피아 게임입니다.

## v2.4 변경 사항

- 교사 화면을 `학생 현황 + 현재 진행` 중심으로 단순화했습니다.
- 투표와 밤 행동을 여러 카드로 나누지 않고, 현재 단계에 필요한 메뉴만 표시합니다.
- 역할 설정은 역할 배정 전까지만 표시됩니다.
- 가상 학생, 지난 기록, 게임 관리는 접이식 메뉴로 정리했습니다.
- 밤 결과에 마피아 선택, 의사 보호와 함께 **경찰 조사 대상과 판정(마피아 / 마피아 아님)** 이 표시됩니다.
- 지난 기록에도 경찰 조사 결과가 남습니다.
- 학생 화면은 `내 역할(열려 있을 때만) + 지금 해야 할 행동`만 표시합니다.
- 학생 역할이 잠기면 역할 카드는 화면에서 사라집니다.
- 투표 종료 후 학생에게 전체 득표 결과를 보여주지 않고 대기 화면만 표시합니다.
- 경찰 학생은 밤 종료 후 개인 결과만 별도로 확인할 수 있습니다.

## 기존 기능

- QR 입장 / 인터넷 접속
- 역할 배정 및 교사 역할 가림
- 학생 역할 잠금
- 일차별 투표 및 탈락 처리
- 전원 공통 밤 행동
- 마피아 처단 / 의사 보호 / 경찰 조사 / 시민 더미 행동
- 가상 학생 테스트
