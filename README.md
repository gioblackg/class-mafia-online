# 우리 반 마피아 Online v2.1

교사와 학생이 서로 다른 Wi-Fi/LTE/5G에서도 사용할 수 있는 인터넷 배포형 교실 마피아 게임입니다.

## v2.1 변경 사항

- 학생 투표 후보를 체크한 뒤 자동 새로고침이 되어도 선택이 풀리지 않도록 수정
- 교사 화면의 학생 역할은 기본적으로 `•••`로 가림
- 교사가 필요할 때만 `역할 보기` 버튼으로 확인 가능
- `학생 역할 잠금` 버튼 추가: 잠그면 모든 학생 화면에서 역할이 즉시 가려짐
- 잠금을 다시 열면 학생이 자신의 역할을 다시 확인 가능
- 교사용 `밤 진행` 체크표 추가
  - 마피아가 지목한 학생 체크
  - 의사가 보호한 학생 체크
  - 같은 학생이면 보호 성공
  - 다르면 마피아 지목 학생 자동 탈락
  - 밤 결과 기록 보관

## Render 업데이트 방법

현재 GitHub 저장소 `class-mafia-online`에 이 버전의 파일을 덮어 올리면 Render가 자동으로 새 버전을 배포합니다.

가장 간단한 방법:
1. 이 ZIP을 컴퓨터에서 압축 해제
2. GitHub `class-mafia-online` 저장소에서 `Add file` → `Upload files`
3. 압축 해제한 폴더 안의 파일/폴더를 모두 업로드
4. `Commit changes`
5. Render에서 자동 배포가 끝나고 `Live`가 되면 기존 주소를 그대로 사용

기존 주소 예: `https://class-mafia-online.onrender.com`
