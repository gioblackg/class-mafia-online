# 우리 반 마피아 Online v2.8 업데이트

기존 GitHub `class-mafia-online` 저장소에 이 폴더 안의 파일을 같은 위치로 덮어 업로드한 뒤 `Commit changes`를 누르세요.
Render가 자동으로 재배포하며 기존 사이트 주소는 유지됩니다.

## v2.8 변경 사항
- 교사 메인 화면에서 학생 목록/상태표를 완전히 제거했습니다.
- 학생 접속 명단은 QR 확대 화면에서만 확인합니다.
- 전체 역할은 `전체 역할 새창`에서만 확인합니다.
- 메인 오른쪽 화면은 현재 진행/투표 결과/밤 결과/지난 기록 중심으로 정리했습니다.
- 역할 배정 전 버튼은 `역할 부여`, 배정 후에는 `✓ 부여 완료`로 바뀌며 비활성화됩니다.
- 역할 배정 후 `전체 역할 새창`, `역할 잠금/열기` 버튼은 왼쪽 게임 준비 카드에 남습니다.
