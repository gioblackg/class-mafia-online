# 우리 반 마피아 Online v2.10

v2.9의 게임풍 디자인과 기존 기능은 그대로 유지하면서 **밤 행동 진행 오류와 재접속 역할 변경 문제**를 수정한 버전입니다.

## 수정 1: 밤 행동을 모두 하지 않아도 교사가 진행 가능
- 밤 행동 완료 인원은 계속 표시됩니다.
- 일부 학생이 미완료여도 `밤 결과 확인` 버튼을 누를 수 있습니다.
- 미완료 학생이 있으면 확인창이 한 번 뜹니다.
- 계속 진행하면 미완료 학생의 행동은 `선택 없음`으로 처리됩니다.
- 따라서 결석, 접속 끊김, 태블릿 절전 등으로 한 학생이 행동하지 못해도 게임이 멈추지 않습니다.

## 수정 2: 재접속 시 역할 유지
- 역할 부여 API를 서버에서 1회만 실행하도록 잠갔습니다. 중복 클릭/중복 요청이 들어와도 역할을 다시 섞지 않습니다.
- 학생 태블릿 브라우저에 난수 기반 `기기 재접속 ID`를 저장합니다.
- 같은 태블릿 + 같은 브라우저라면 방 토큰이 유실되어도 서버가 기존 학생을 찾아 같은 역할/생존 상태로 복원합니다.
- 동일 이름의 새 학생을 게임 중 새로 만들 수 없으므로 중복 역할 생성도 막습니다.
