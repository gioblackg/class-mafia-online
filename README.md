# 우리 반 마피아 Online v2.12

기능은 v2.11과 동일하며, 교사용 **밤 결과 확인 화면만 크게 표시하는 방식**으로 개선했습니다.

## v2.12 변경
- `밤 결과 확인`을 누르면 QR 확대처럼 큰 전용 결과 화면이 자동으로 열립니다.
- `마피아 선택`, `의사 보호`, `경찰 조사`를 각각 버튼으로 눌러 하나씩 공개합니다.
- 공개된 항목은 같은 버튼을 다시 눌러 가릴 수 있습니다.
- 세 항목을 모두 공개하면 하단에 최종 밤 결과가 크게 나타납니다.
- 큰 화면을 닫은 뒤에는 메인 화면의 `밤 결과 크게 보기` 버튼으로 다시 열 수 있습니다.
- 그 외 역할, 투표, 재접속, 이름 변경, 테스트 기능은 변경하지 않았습니다.
