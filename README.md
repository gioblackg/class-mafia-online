# 우리 반 마피아 Online v2.5

교실에서 태블릿으로 사용하는 인터넷 배포형 마피아 게임입니다.

## v2.5 변경 사항

- 교사 화면의 QR을 누르면 **전체화면에 가깝게 크게 확대**됩니다.
- 확대 QR 아래에 현재 실제로 접속 중인 학생 이름과 인원이 작게 표시됩니다.
- 게임 준비에서 **시작 일차(1~99)** 를 정한 뒤 역할을 배정할 수 있습니다.
- 학생 접속이 잠시 끊겨도 인증 정보를 지우지 않고 **자동으로 재연결**합니다.
- 같은 태블릿의 같은 브라우저에서 QR을 다시 열어도 기존 학생 상태를 이어갑니다.
- 기존 v2.4의 간소화 UI, 일차별 투표, 역할 잠금, 전원 공통 밤 행동, 경찰 조사 결과, 가상 학생 테스트를 유지합니다.

## 학생 재접속 범위

같은 태블릿 + 같은 브라우저에서는 학생용 비밀 접속 토큰이 브라우저 저장소에 남기 때문에 새로고침, 일시적인 Wi-Fi 끊김, 탭을 닫았다가 같은 방 QR을 다시 여는 경우에 기존 상태를 이어갑니다.

다른 태블릿/다른 브라우저, 시크릿 모드, 브라우저 데이터 삭제, 서버 자체 재시작/재배포 후에는 이 정보만으로 복구할 수 없습니다.
