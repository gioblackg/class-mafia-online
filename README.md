# 우리 반 마피아 Online v2.3

교사와 학생이 서로 다른 Wi-Fi/LTE/5G에서도 사용할 수 있는 인터넷 배포형 교실 마피아 게임입니다.

## v2.3 변경 사항

- **경찰 조사 결과 표시 수정**
  - 밤에 경찰이 조사한 뒤 같은 밤에 탈락하더라도 조사 결과를 확인할 수 있습니다.
  - 밤 결과가 적용된 뒤 `개인 결과 확인` 영역을 누르고 있는 동안 조사 대상과 `마피아입니다 / 마피아가 아닙니다` 결과가 표시됩니다.
- **가상 학생 테스트 모드 추가**
  - 교사 화면에서 1~12명의 `테스트1, 테스트2...` 가상 학생을 추가할 수 있습니다.
  - 실제 기기 3대가 없어도 가상 학생을 포함해 3명 이상이면 역할을 배정할 수 있습니다.
  - 각 가상 학생의 `학생 화면 보기` 버튼으로 그 학생 화면을 새 탭에서 직접 확인할 수 있습니다.
  - 밤 행동 중 `가상 학생 밤 행동 자동 선택`으로 가상 학생의 행동을 한 번에 완료할 수 있습니다.
  - 낮 투표 중 `가상 학생 투표 자동 선택`으로 가상 학생의 투표를 한 번에 완료할 수 있습니다.
  - 역할 보기로 경찰 학생을 확인한 뒤 해당 가상 학생 화면을 열면 경찰 조사 결과 동작을 쉽게 시험할 수 있습니다.
- 가상 학생은 실제 학생과 구분되도록 교사 화면에 `🧪 가상`으로 표시됩니다.

## v2.2 기능 유지

- 생존 학생 전원에게 같은 밤 행동 화면 표시
- 마피아 처단 / 의사 보호 / 경찰 조사 / 시민 더미 행동
- 학생별 후보 순서 랜덤 고정
- 태블릿에서 약 0.8초 꾹 눌러 밤 행동 선택
- 학생 역할 자동 잠금
- 일차별 마피아 투표와 탈락 처리
- 교사 화면 역할 기본 가림
- QR 입장 및 인터넷 접속
