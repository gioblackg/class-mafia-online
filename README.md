# 우리 반 마피아 Online v2.7

교실에서 태블릿으로 사용하는 인터넷 배포형 마피아 게임입니다.

## v2.7 변경 사항

- 교사 메인 진행판에서 학생 역할 표시를 완전히 분리했습니다.
- `📋 전체 역할 새창` 버튼을 누르면 별도의 교사용 역할 현황판이 열립니다.
- 역할 현황판에서는 전체 학생의 이름/역할/생존 상태와 역할별 인원수를 한 화면에서 확인할 수 있습니다.
- 새 역할 창은 1.5초마다 자동 갱신되어 탈락 상태도 바로 반영됩니다.
- 메인 진행판에는 투표·밤 행동·탈락 처리 등 진행 정보만 남아 화면이 더 단순해졌습니다.
- 교사 화면의 QR을 누르면 **전체화면에 가깝게 크게 확대**됩니다.
- 확대 QR 아래에 현재 실제로 접속 중인 학생 이름과 인원이 작게 표시됩니다.
- 게임 준비에서 **총 진행 일수(1~30일)** 를 정한 뒤 역할을 배정할 수 있습니다.
- 학생 접속이 잠시 끊겨도 인증 정보를 지우지 않고 **자동으로 재연결**합니다.
- 같은 태블릿의 같은 브라우저에서 QR을 다시 열어도 기존 학생 상태를 이어갑니다.
- 기존 v2.4의 간소화 UI, 일차별 투표, 역할 잠금, 전원 공통 밤 행동, 경찰 조사 결과, 가상 학생 테스트를 유지합니다.

## 학생 재접속 범위

같은 태블릿 + 같은 브라우저에서는 학생용 비밀 접속 토큰이 브라우저 저장소에 남기 때문에 새로고침, 일시적인 Wi-Fi 끊김, 탭을 닫았다가 같은 방 QR을 다시 여는 경우에 기존 상태를 이어갑니다.

다른 태블릿/다른 브라우저, 시크릿 모드, 브라우저 데이터 삭제, 서버 자체 재시작/재배포 후에는 이 정보만으로 복구할 수 없습니다.

## 업데이트

기존 GitHub 저장소 `class-mafia-online`에 업데이트 ZIP의 파일을 덮어 올리고 `Commit changes`를 누르면 Render가 자동 재배포합니다.


## v2.6에서 유지되는 변경 사항
- 게임 시작 전에 **총 진행 일수**를 1~30일로 설정합니다. 게임은 항상 1일차부터 시작하며 마지막 일차의 밤 결과가 끝나면 자동으로 게임 종료 상태가 됩니다.
- 학생 역할 카드는 마피아/경찰/의사/시민 모두 같은 색, 같은 배경, 같은 크기를 사용하며 화면에 보이는 차이는 역할 글자뿐입니다.
- 마피아 동료 정보는 평소에는 보이지 않고, 모든 역할에게 동일하게 보이는 `비밀 정보 확인` 버튼을 누르고 있는 동안만 표시됩니다.
